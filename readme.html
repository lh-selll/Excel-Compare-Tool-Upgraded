使用指南

快速掌握Excel对比工具的核心功能和操作流程，高效完成Excel文件对比任务

主界面介绍

打开程序后，主界面包含以下核心区域，各区域功能清晰明确：

一键清空配置按钮

点击"One-click clear"按钮，可快速清空所有配置信息和文件选择信息

文件选择区域

分别选择"文件1"和"文件2"，支持.xlsx、.xls、.xlsm和.csv格式文件

选项卡区域

包含"Compare Config"选项卡，用于配置对比相关的详细信息

进度和按钮区域

包含进度条和"开始处理"按钮，支持开始/停止对比处理操作

结果区域

实时显示对比处理的结果信息，对比完成后告知输出文件保存路径

当前Task区域

实时显示当前正在执行的任务信息，便于了解处理进度

使用步骤

1

选择文件

  • 在文件选择区域，分别点击"文件1"和"文件2"后的"浏览"按钮
  • 选择需要对比的两个Excel文件，支持格式：.xlsx、.xls、.xlsm、.csv
  • 选择文件后，程序会自动获取文件中的工作表名称
  • 根据文件的sheet数量，设置需要对比的sheet数量

提示：

选择文件后，工作表名称会自动填充到"Compare Config"选项卡中，供后续选择

2

配置对比信息

进入"Compare Config"选项卡，按以下步骤完成配置：

1. 选择工作表

  • 在"文件1-sheet"和"文件2-sheet"列中，分别选择要对比的工作表
  • 两个工作表都选择后，其他列的配置控件将自动启用

2. 选择对比模式

N（不映射）

直接根据索引列进行对比，索引列需输入大写字母表示列号（如"A"、"B"）

Y（映射）

按表头映射对比，需指定表头行数，索引列从一致的表头名称中选择

3. 指定索引列

  • 支持设置1-3个索引列，可选择多列组合作为索引列
  • 不映射模式：直接输入大写字母列号
  • 映射模式：从下拉框中选择一致的表头名称
3

开始对比

  • 确认所有配置信息完整无误后，点击"开始处理"按钮
  • 处理过程中，进度条会实时显示处理进度
  • "当前正在执行的Task区域"会显示实时任务信息
  • 如需终止对比，可点击"停止处理"按钮中断进程

注意

停止对比会终止当前进程，已处理的数据可能无法保存，请谨慎操作

4

查看结果

  • 对比完成后，结果会显示在"结果区域"
  • 程序会弹出消息框提示对比完成，并告知输出文件保存路径
  • 输出文件格式：原文件名 - compare.xlsx
  • 文件默认保存在指定的outputfile文件夹中

提示

建议对比完成后及时查看输出文件，确认对比结果是否符合预期

5

其他操作

一键清空配置

  • 点击"One-click clear"按钮，可清空所有配置信息和文件选择信息
  • 适用于需要重新配置对比任务的场景
  • 清空后需重新选择文件并配置对比信息

错误处理

  • 处理过程中出现错误会在结果区域显示错误信息
  • 常见错误：文件格式不正确、配置信息不完整、工作表重复等
  • 根据错误提示修正后可重新发起对比

注意事项

文件格式要求

确保选择的Excel文件存在且格式正确，支持.xlsx、.xls、.xlsm和.csv格式

配置完整性

至少保证一行配置完整，包括工作表名称、至少一个索引列，映射模式需指定表头行数

重复元素警告

工作表列中存在重复元素时，程序会弹出警告框提示配置错误，请及时修正
